# 1636架构介绍

## 简介

1636是一款基于ARM V9指令集的通用CPU。1636是一款针对HPC进行了专项优化的鲲鹏处理器。

| 规格     |             | 指标                                     |
| -------- | ----------- | ---------------------------------------- |
| 基本规格 | ISA         | ARMV9 SVE2+SME                           |
|          | 核数        | 304                                      |
|          | SME主频     | 1.55G                                    |
|          | Scalar主频  | 2GHz                                     |
|          | L1D         | 32KB                                     |
|          | L1I         | 32KB                                     |
|          | Private L2  | 768KB                                    |
|          | Issue Width | 4                                        |
|          | 整芯片功耗  | 690W                                     |
|          | HBM容量     | 8*4G                                     |
|          | HBM带宽     | 8*0.5TBps                                |
|          | DDR通道     | 8                                        |
|          | DDR速率     | 5600Mbps                                 |
| SME算力  | FP64        | 60                                       |
|          | FP32        | 120                                      |
|          | FP16        | 240                                      |
|          | BF16        | 240                                      |
|          | INT8        | 960                                      |
| SVE算力  | FP64        | 17                                       |
|          | FP32        | 34                                       |
|          | FP16        | 68                                       |
|          | BF16        | 68                                       |
|          | INT8        | 136                                      |
| IO规格   | PCIe        | 4组x8(5.0)(每组x8和HCCS H32共用，二选一) |
|          | HCCS(H32)   | 4组x8(每组和PCIE互斥，二选一)            |
|          | HCCS(H60)   | 8组x4                                    |
|          | Network     | 4组 200G/100G/25G/10G                    |
|          | SATA        | 2组(3.0)                                 |
|          | USB         | 2组(2.0)                                 |



1636是一个使用复杂工艺封装的多DIE芯片，一共有14颗DIE，包含有2颗计算DIE，8颗HBM DIE，4颗IO DIE。其中，1颗计算DIE，4颗HBM DIE，和2颗IO DIE使用2.5D封装，放在一个基板上行程一个整体，称之为一个ICD。2个ICD通过MCM封装为一个1636芯片。

整芯片一共有304Core，被分成8个Cluster，每一个Cluster有38Core，通过目录结构(UC)维护cache一致性。Cluster内部的38个Core通过一个专门的片上环形总线(c-ring)连接在一起，并在两端有目录结构（UC）维护cache一致性。UC的后端是HBM颗粒。
